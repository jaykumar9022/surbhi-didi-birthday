# 🎉 Happy Birthday Surbhi Didi 💙

A beautiful and interactive birthday surprise website created especially for **Surbhi Didi** using **HTML, CSS, and JavaScript**.

This project is a small token of love and appreciation, designed to make her birthday memorable with beautiful animations, heartfelt messages, music, and interactive surprises.

## ✨ Features

- 🎂 Live Birthday Countdown
- 💌 Animated Birthday Message
- 🪙 Scratch Card Surprise
- 💬 Interactive Chat Story
- 📸 Photo Gallery with Lightbox
- 🎁 Surprise Gift Boxes
- 🎵 Background Music
- 🎂 Interactive Birthday Cake
- 🎉 Confetti & Celebration Effects
- 💖 Floating Hearts & Animations
- 📱 Fully Responsive Design

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
